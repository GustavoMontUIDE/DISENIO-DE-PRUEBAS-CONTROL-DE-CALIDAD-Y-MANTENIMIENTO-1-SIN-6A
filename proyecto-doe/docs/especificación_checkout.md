# Especificación del Módulo de Checkout

## Factores definidos

| Factor         | Descripción                | Niveles |
|----------------|----------------------------|---------|
| Tipo de cliente | Perfil                     | Nuevo, Recurrente, Invitado, Empresa, VIP |
| Método de pago | Medio de pago              | Tarjeta, PayPal, Transferencia, Contraentrega, Cripto |
| Dispositivo    | Medio de acceso            | Movil, Desktop, Tableta, SmartTV, Consola |
| Estado de red  | Condición                  | Buena, Media, Lenta, Intermitente, SinConexion |
| Región fiscal  | Impuestos / regulación     | LATAM, EU, US, APAC |
| Envío (opcional) | Logística                 | Economico, Estandar, Express, Pickup |

Este documento acompaña la generación del DOE y Pairwise.
